# CloseCook Concept Demo

Responsive single-page concept website for a CloseCook student startup presentation.

## Run locally

Open `index.html` in any modern browser. No dependencies, build steps, backend, API keys, ordering, or payments are included.

## Publish with GitHub Pages

1. Create a public GitHub repository named `closecook-demo`.
2. Upload `index.html` and `README.md` to the repository root and commit them to `main`.
3. On GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. GitHub will display the published Pages URL once the build completes.

## Scope

This is an academic concept demo. All chefs, dishes, prices, and profiles are illustrative and fictional. The modal only previews a hypothetical order; it does not submit an order, contact a chef, reserve food, collect data, or process payment. Food-safety checks and customer research are not represented or claimed.

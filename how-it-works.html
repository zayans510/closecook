How it works

A simple path from menu to handover.

The CloseCook concept uses advance pre-orders and a defined pickup process to make coordination clearer for residents and home chefs.

01

Discover

Residents browse nearby sample menus, meal descriptions, indicative prices and stated availability.

02

Pre-order

The resident selects a meal, quantity and preferred window. In a real service, the chef would confirm availability.

03

Coordinate pickup

Both sides receive the agreed pickup window and designated handover point, without publishing a home address.

04

Confirm handover

A one-time code could confirm the handover in a future implementation. This demo does not generate real order codes.

For residents

Know what you are choosing.

The proposed resident journey prioritizes clarity before commitment.

  • Browse menu items and sample prices.
  • Review ingredient and allergen information where available.
  • Choose a proposed pickup window.
  • See order status and handover details in a future version.

For home chefs

Plan portions with more certainty.

Advance ordering could help a cook estimate quantities and avoid accepting more orders than they can prepare.

  • Set daily menu and availability.
  • Set an order cap and cutoff time.
  • Confirm orders before preparing food.
  • Keep personal contact details private where possible.
Before a real launch

Trust has to be earned.

The process below is a proposed checklist, not a claim that checks have already been completed.

A

Food safety

Investigate applicable FSSAI registration/licensing, hygiene practices, ingredient disclosure and allergen handling.

B

Clear policies

Define cancellations, refunds, complaints, payment handling and responsibility for each order.

C

Small pilot

Validate customer demand, chef capacity, repeat use and unit economics before scaling beyond one society.

This website is a concept prototype.
